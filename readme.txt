Novel Application of Stereotaxically Guided Dental Germinative 
Photodynamic Regulation in Chinchilla lanigera with 
Refractory Malocclusion.

Authored and Developed by Daniel B. B. Fraser

DOI: https://doi.org/10.5281/zenodo.18203469

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This repository contains an open-source paper which covers photodynamic
therapy as a potential treatment option for refractory malocclusion
cases in chinchillas and other elodonts, particularly in cases of 
excessive growth, inadequate wear, and retrograde elongation.

There is also supporting documentation providing details on a
patient-specific stereotaxic device, dubbed Auriel, which was designed
to provide a stable, secure platform for the procedure. The model files
for this device are not released, to prevent it from being used against
advisement on chinchillas that it was not designed for.

Lastly, there is an attached software package for the validation of MCX
simulations graphed in the appendix of the paper. These are validation
structures with exact command line arguments for the user to enter, to
allow for exact reproducibility.

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Further details on the software package can be found in the readme files
contained in each subfolder.
